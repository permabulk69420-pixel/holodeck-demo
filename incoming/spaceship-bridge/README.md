# Spaceship bridge panoramas (incoming)

Free 360 panorama pack, licensed **CC0 1.0 (public domain)**, so it is fine to keep and serve from this public repo.
Attribution is appreciated but not required: add the pack name and author here when known.

- `original/`: the JPGs (1.jpg ... 10.jpg), about 2.5 MB each. Upload a few here to start.
- `processed/`: the larger PNG versions (1p.png ... 10p.png). Optional; only needed if the originals are low-res.

Files that pass a check (2:1 equirect, enough resolution, clean poles) get moved to `assets/` and wired up as scenes.
